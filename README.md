# Relay CI/CD landing page

A lightweight landing page introducing a clear CI/CD workflow from commit to
production. Built with Next.js App Router and responsive, hand-written CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the page.

## Quality checks

```bash
npm run lint
npm run build
```
